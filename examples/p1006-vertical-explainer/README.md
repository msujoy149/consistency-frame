# P1-006 reference project — vertical explainer

One complete, reproducible vertical-video production: a 30–60 s,
1080x1920, 30 FPS, H.264/AAC MP4 with real narration, synthesized
music/room-tone/SFX, FFmpeg-generated motion-graphics visuals, a
canonical timeline, FFmpeg assembly, technical/visual/audio QC, and
a delivery package.

## Honest scope

- **Narration is real.** The delivery render uses VoiceStudio /
  OmniVoice (local, non-commercial) with a fixed seed and the fixed
  `middle-aged, moderate pitch` instruct tag. The narration WAVs are NOT committed to
  this repo (`.gitignore` forbids generated media); they live in the
  delivery archive with SHA-256 hashes in the asset manifest.
- **Visuals are real but locally generated.** Each shot is a
  deterministic FFmpeg motion-graphics clip (animated gradient,
  moving accent, keyword text). They are labelled
  `ffmpeg-local` in every record — NOT AI image or video
  generation. No external image/video provider was used or is
  claimed; all eight P1-005 provider contracts stay NOT_TESTED.
- **Music, room tone, and SFX are synthesized** locally with FFmpeg
  and labelled `synthesized` in every record.
- **CI render differs in one recorded way.** CI has no VoiceStudio
  model, so the CI render synthesizes a tone track of the planned
  line durations instead of narration. Same pipeline, same
  geometry, same QC — only the voice source differs, and the CI
  delivery manifest says so. The delivered MP4 always carries the
  real narration.
- **No AI visual-quality review is claimed.** Visual QC is a
  contact sheet, key frames, and measured reports for human
  review; editorial approval stays human.

## Files

- `project.json` — project config, output profile, audio profile.
- `script.md` — original narrator script (6 lines, verbatim).
- `production-analysis.json` — analysis (narrator-only; no characters).
- `shot-list.json` — 6 shots with FFmpeg visual recipes.
- `voice-config.json` — narrator lines, seed, instruct tag.
- `sound-plan.json` — tracks, SFX cues, intentional silence.
- `assembly-config.json` — the single FFmpeg render path.
- `timeline-manifest.json` — generated by the pipeline (recorded evidence).
- `qc-report.json` — generated by the pipeline (recorded evidence).
- `delivery-manifest.json` — generated by the pipeline (recorded evidence).

## Run it

`python3 scripts/run-p1006-reference-render.py --help`

The driver loads this project, generates the visuals, synthesizes
the audio beds, assembles with FFmpeg, runs QC, and writes the
delivery package under
`~/workspace/consistency-frame-p1-delivery/p1006/dist/p1006-vertical-explainer/`.
With `--voice-dir` it uses real VoiceStudio WAVs; without it, it
synthesizes the tone narration used by CI.
