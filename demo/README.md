# Demo Project

This folder is intentionally empty.

Consistency Frame ships with an **on-demand demo system**: a sample
character and a sample episode, provided only when you ask for one —
never forced, never shipped in the repo. There is no demo content in
this repository yet, and none will be added without being requested.

To get a demo, ask the installed assistant for one. It will register a
sample character, generate a sample episode, and walk you through what
each system does — then you can delete it, or keep it as the starting
point of your own series.
