## What P0 builds (and does not build)

Build: non-destructive skill sync (`scripts/sync-skills.sh`) + split installer
(`setup.sh`: core-only by default, `--with-components` opt-in); canonical
registries (`registry/*.json`, generated by `scripts/generate-registries.py`);
versioned JSON Schemas (`schemas/*.json`); asset-mode policy
(`scripts/asset_policy.py`); audio delivery profiles
(`architecture/audio-delivery-profiles.json`); tests (`tests/`);
GitHub Actions CI (`.github/workflows/p0-ci.yml`); living architecture report
(generated from registries); capability records (`architecture/*`,
`registry/adapters.json`); targeted fixes for F1–F9 above; build report and
release manifest.

Do NOT build in P0: media-analysis runtime, frame extraction, OCR/ASR,
automatic reference learning, fine-tuning, script-to-performance compiler
runtime, generation-provider calls, live NLE editing, rendering adapters,
benchmark lab, auto-repair, motion capture, distributed workflow engine,
publishing/deployment automation. Schemas, contracts and roadmaps only.

Existing skills are preserved: no skill is rewritten wholesale and no
duplicate skill is created. The 15 skills stay 15.
